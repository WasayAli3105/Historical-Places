# Historical Places Website

A simple, static website for exploring **famous historical places** across different regions (East, West, North, South). The project is built using **HTML, CSS, and Bootstrap**.

---

## Project Structure

At the root of this folder you will find:

- `index.html` — Home page (carousel + featured cards)
- `about.html` — About section/page
- `Contact.html` — Contact page (uses `Contact.css`)
- `gallery.html` — Gallery page (uses `gallery.css`)
- `east.html` / `east.css` — East region page
- `west.html` / `west.css` — West region page
- `north.html` / `north.css` — North region page
- `south.html` / `south.css` — South region page

Common styling files:
- `about.css`
- `gallery.css`
- `Contact.css`
- `east.css`, `west.css`, `north.css`, `south.css`

## Installation / Setup

This is a static site. No build system or package installation is required.

### Requirements
- A modern web browser (Chrome/Edge/Firefox)

### Steps
1. Download/clone/copy this project folder.
2. Open `index.html` in your browser.
3. Use the navigation/menu to visit other pages.

---

## How to Run

Because it’s static content:

- **Option A (Quick):** Right-click `index.html` → Open with your browser.
- **Option B (Local server, optional):**
  - If you want to avoid any browser restrictions for local files, run a local static server using any simple tool (e.g., VS Code Live Server).

## Notes
